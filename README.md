This Overleaf and GitHub project is based on observations of how the UN Sustainable Development Goals (SDGs) are used alongside documents in KTH's DiVA.

These observations provide some case studies and have guided the development of the script sdg_classifier_dual_language.py that is available from [KTH-3rd-cycle-template-restructured--testing](https://github.com/gqmaguirejr/KTH-3rd-cycle-template-restructured--testing).

View the program and this document as a work in progress.
